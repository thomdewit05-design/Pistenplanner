En bref

  • Skipilot n'a ni comptes ni services d'analyse. Le site web n'affiche pas de publicités ; l'application iPhone gratuite affiche des publicités de Google AdMob (voir ci-dessous).
  • Skipilot n'a ni comptes ni services d'analyse. L'application et le site web affichent des publicités de Google ; pour cela, Google vous demande d'abord votre consentement aux cookies.
  • Vos itinéraires, vos réglages, votre carnet de ski et vos lieux enregistrés se trouvent uniquement sur votre propre téléphone.
  • Votre position est utilisée sur votre téléphone pour la navigation. C'est seulement si vous utilisez vous-même un groupe que votre position est envoyée aux membres de votre groupe, sous forme chiffrée.
  • L'application n'utilise Santé d'Apple, les photos et le capteur de mouvement que si vous l'activez vous-même. Ces données restent sur votre propre téléphone.

Ce qui reste sur votre téléphone

L'application conserve dans le stockage de votre téléphone (ou de votre navigateur) : vos réglages (niveau, préférences, thème, langue), vos itinéraires enregistrés et vos favoris, votre carnet de ski avec les points GPS de vos journées de ski, l'emplacement de votre hôtel ou de votre voiture, les pistes que vous avez fermées, le nom et le code de votre groupe, vos photos, votre poids (si vous le saisissez), les domaines skiables téléchargés et, si vous avez Pro, votre code de licence. Ces données ne sont envoyées nulle part. Vous pouvez les effacer via Menu > Stockage et confidentialité, ou en supprimant l'application.

Votre position

Si vous donnez votre autorisation, l'application utilise le GPS de votre téléphone pour vous afficher sur la carte, naviguer, tenir votre carnet de ski et indiquer votre vitesse. Cela se passe sur votre téléphone. Votre position n'est envoyée à d'autres personnes que si vous faites partie d'un groupe et que « Partager ma position » est activé (voir ci-dessous).

Santé d'Apple (application iPhone)

Si vous activez « Enregistrer dans Santé », votre iPhone vous demande d'abord votre autorisation. Après une journée de ski, l'application l'enregistre comme entraînement dans Santé d'Apple : l'heure de début et de fin, la distance et une estimation des calories. Pour cette estimation, vous pouvez saisir votre poids ; il reste sur votre téléphone. L'application ne lit rien dans Santé d'Apple et n'envoie ces données nulle part. Les données de santé ne sont jamais utilisées pour la publicité.

Photos, capteur de mouvement et Apple Watch

Les photos que vous prenez ou choisissez pour votre journée de ski ne sont conservées par l'application que sur votre téléphone. L'application utilise le capteur de mouvement pendant l'enregistrement d'une journée de ski pour reconnaître les sauts ; cela aussi se passe sur votre téléphone. Si vous avez l'application Apple Watch, votre iPhone envoie votre journée de ski et votre itinéraire directement à votre montre. Les widgets et l'Activité en direct affichent des données qui se trouvent déjà sur votre téléphone.

Domaines skiables téléchargés

Avant d'utiliser un domaine skiable, vous le téléchargez : les données des pistes et les données d'altitude pour la carte d'hiver et la 3D sont alors conservées sur votre téléphone, afin que tout fonctionne sans réseau. Vous les effacez via Menu > Stockage et confidentialité.

Publicités dans l'application iPhone

Dans l'application iPhone gratuite, nous affichons des publicités de Google AdMob (Google Ireland Limited). Lors de la première utilisation, un message de Google vous demande votre consentement aux publicités personnalisées, puis votre iPhone vous demande si Skipilot peut suivre vos activités. Si vous refusez, vous recevez des publicités qui ne sont pas adaptées à vous. Vous modifiez votre choix auprès de Google dans l'application via Menu → Confidentialité des publicités, et celui auprès d'Apple via Réglages → Confidentialité et sécurité → Suivi. En savoir plus sur AdMob : policies.google.com/technologies/ads.

Publicités et cookies

Pour que Skipilot reste gratuit, le site web et l'application affichent des publicités de Google AdSense (Google Ireland Limited). Lors de votre première visite, un message de Google vous demande si vous consentez aux cookies et aux publicités personnalisées. Si vous ne donnez pas votre consentement, vous recevez des publicités qui ne sont pas adaptées à vous ; Google n'utilise alors que ce qui est nécessaire pour afficher des publicités et lutter contre les abus.

Vous pouvez modifier votre choix à tout moment via le bouton ou le petit bouclier que Google affiche en bas de la page, ou en effaçant les cookies de ce site web dans votre navigateur. En savoir plus sur la manière dont Google utilise les données : policies.google.com/technologies/partner-sites.

Pourquoi est-ce permis (base juridique)

Les données sont utilisées pour faire fonctionner l'application comme vous le demandez (exécution du contrat) et, en cas d'achat, pour respecter l'obligation légale de tenue d'une comptabilité. Pour les publicités personnalisées dans l'application iPhone, la base juridique est votre consentement. Pour les cookies et les publicités personnalisées, la base juridique est votre consentement. Pour votre position, votre téléphone vous demande d'abord votre autorisation ; vous pouvez la retirer à tout moment dans les réglages de votre téléphone.

Combien de temps

Les données sur votre téléphone y restent jusqu'à ce que vous les effaciez. Les messages de groupe disparaissent de ntfy.sh après un court délai. Les données de commande sont conservées sept ans, parce que la législation fiscale l'exige.

Vos droits

Vous pouvez demander quelles données vous concernant existent, les faire rectifier ou supprimer, et vous opposer à leur traitement. Écrivez pour cela à [adresse e-mail]. Si vous n'êtes pas satisfait de la manière dont vos données sont traitées, vous pouvez introduire une réclamation auprès de l'Autoriteit Persoonsgegevens (l'autorité néerlandaise de protection des données).

Modifications
