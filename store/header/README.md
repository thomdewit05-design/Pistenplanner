# Header voor de App Store

`skipilot-header-nl.png` en `skipilot-header-en.png`: 3840×2160 (16:9), RGB zonder transparantie.

Te gebruiken als promotie-afbeelding:
- in App Store Connect bij **Featuring Nominations** (promotie-artwork), en bij een **In-App Event** (afbeelding van het evenement);
- op de website en voor sociale media.

Zelf aanpassen: open `header.html` in een browser (`#nl` of `#en` achter de link). Opnieuw maken op 3840×2160 kan met
Playwright: venster 1920×1080 en `deviceScaleFactor: 2`.
